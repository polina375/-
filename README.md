# Альфа-Курс: ИИ-помощник для предпринимателей в Telegram (Трек 2)

## Назначение
АльфаБро - Telegram-бот, который помогает начинающим предпринимателям и владельцам малого бизнеса получать ответы на вопросы по базе знаний «Альфа-Курса».

Бот уточняет неоднозначные запросы, сообщает об отсутствии информации в базе знаний, рекомендует подходящие бесплатные и платные образовательные материалы с ссылками на платформу, учитывает профиль пользователя и сохраняет историю диалога.

Также бот позволяет создавать разовые и повторяющиеся напоминания об обучении и важных событиях в бизнесе.

Цель решения - упростить доступ к образовательным материалам и повысить возвращаемость пользователей на платформу «Альфа-Курс».

## Архитектура

```text
Telegram ──► bot/ (интерфейс, профили, история, напоминания)
                │
                │ answer(user_id, text, profile, history)
                ▼
            rag/assistant.py
              ├─ retriever.py     гибридный поиск: BM25 + эмбеддинги (RRF)
              ├─ llm.py           генерация ответов через GigaChat-2
              ├─ prompts.py       промпты и правила формирования ответов
              └─ recommender.py   рекомендации бесплатных и платных материалов
                                  с учётом профиля пользователя
                │
                ▼
        Ответ и ссылки на материалы «Альфа-Курса»

PostgreSQL (база знаний) ──► rag/ingest.py ──► data/ (чанки и эмбеддинги)

SQLite ──► профили пользователей, история диалогов, напоминания
```

**Основные компоненты:**

- `bot/` — взаимодействие с пользователем через Telegram, управление профилями, историей диалогов и напоминаниями.
- `rag/` — поиск информации в базе знаний, генерация ответов и подбор образовательных материалов.
- `PostgreSQL` — хранение предоставленной организаторами базы знаний «Альфа-Курса».
- `SQLite` — хранение пользовательских данных.
- `GigaChat-2` — языковая модель для формирования ответов на основе найденной информации.


## Быстрый запуск (одна команда)

Для запуска необходим установленный и запущенный Docker Desktop.

Поместите предоставленный организаторами дамп базы знаний в data/alfa_course_hackathon.backup. Данные кейса не включены в репозиторий.

Создайте файл .env на основе .env.example и заполните переменные TELEGRAM_BOT_TOKEN и GIGACHAT_CREDENTIALS. Токен Telegram-бота можно получить через @BotFather, учётные данные GigaChat — через сервис GigaChat API. Остальные параметры настройте по образцу .env.example.

Запустите проект из корневой папки репозитория одной командой:

docker compose -p alfabro up --build -d

При первом запуске Docker создаёт контейнеры, восстанавливает базу PostgreSQL из дампа и формирует поисковый индекс, если он отсутствует. Это может занять несколько минут.
При последующих запусках используются сохранённая база данных и готовый индекс из data/.

## Переменные окружения и внешние API

Конфигурация проекта задаётся через файл `.env`, который создаётся на основе `.env.example`. Рабочие токены и ключи не включаются в репозиторий.

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота |
| `GIGACHAT_CREDENTIALS` | Учётные данные для доступа к GigaChat API |
| `GIGACHAT_SCOPE` | Область доступа к GigaChat API |
| `GIGACHAT_MODEL` | Используемая языковая модель (`GigaChat-2`) |
| `GIGACHAT_VERIFY_SSL` | Настройка проверки SSL-сертификатов |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL |
| `DATABASE_URL` | Строка подключения к базе знаний PostgreSQL |
| `DATA_DIR` | Путь к файлам поискового индекса |
| `MIN_COSINE` | Порог семантической схожести при поиске |
| `URL_PREFIX_COURSE` | Префикс ссылок на курсы |
| `URL_PREFIX_DOCUMENT` | Префикс ссылок на документы |
| `URL_PREFIX_ARTICLE` | Префикс ссылок на статьи |
| `URL_PREFIX_PODCAST` | Префикс ссылок на подкасты |
| `URL_PREFIX_GLOSSARY` | Префикс ссылок на материалы глоссария |
| `URL_PREFIX_CALCULATOR` | Префикс ссылок на калькуляторы |
| `URL_PREFIX_WEBINAR` | Префикс ссылок на вебинары |

### Подключение GigaChat API

Для генерации ответов используется сервис **GigaChat API**, модель **GigaChat-2**.

Необходимо получить учётные данные для доступа к API и указать их в переменной `GIGACHAT_CREDENTIALS` файла `.env`.

Модель задаётся через `GIGACHAT_MODEL`, область доступа — через `GIGACHAT_SCOPE`.

Приложение использует эти параметры для обращения к GigaChat API при формировании ответов на основе найденных фрагментов базы знаний.

### Подключение Telegram Bot API

Проект использует Telegram-бота [@AlfaBroHelperBot](https://t.me/AlfaBroHelperBot), разработанного для Hack&Change 2026.

Для подключения необходимо указать токен бота в переменной `TELEGRAM_BOT_TOKEN` файла `.env`.

При самостоятельном запуске эксперты могут создать отдельного тестового бота через [@BotFather](https://t.me/BotFather) и указать его токен в этой переменной.

Бот получает сообщения через **long polling**. Настройка вебхука не требуется.

### Ссылки на образовательные материалы

Для формирования ссылок на материалы используется платформа [«Альфа-Курс»](https://kurs.alfabank.ru/).

Префиксы адресов задаются переменными `URL_PREFIX_...` в файле `.env`. Они используются для формирования ссылок на статьи, курсы, документы и другие образовательные материалы.

## Используемые порты

| Сервис | Порт | Назначение |
|---|---|---|
| PostgreSQL | `5432` | Внутреннее подключение контейнеров к базе знаний |
| PostgreSQL | `55432` | Доступ к PostgreSQL с компьютера разработчика |
| Telegram-бот | Не требуется | Работа через long polling |
| GigaChat API | HTTPS (`443`) | Исходящие запросы к внешнему API |

Для работы бота не требуется открывать входящий HTTP-порт.

## Зависимости

Проект использует следующие технологии:

- **Python 3.12** — основной язык разработки.
- **aiogram 3** — взаимодействие с Telegram Bot API.
- **GigaChat-2** — языковая модель для генерации ответов.
- **BM25 и FastEmbed** — поиск релевантных материалов в базе знаний.
- **PostgreSQL 17** — хранение образовательного контента.
- **SQLite** — хранение профилей, истории диалогов и напоминаний.
- **Docker и Docker Compose** — контейнеризация и запуск проекта.

Python-зависимости перечислены в файле `requirements.txt` и устанавливаются автоматически при сборке Docker-образа.

## Входные данные

Основным источником информации является база знаний образовательной платформы «Альфа-Курс», предоставленная организаторами Hack&Change 2026.

### Дамп базы знаний

Файл: `data/alfa_course_hackathon.backup`

Дамп содержит образовательные материалы, в том числе статьи, курсы, уроки, документы, вебинары, подкасты, глоссарий и калькуляторы.

При первоначальном запуске данные восстанавливаются в PostgreSQL.

### Поисковый индекс

Для поиска используются файлы:

- `data/chunks.jsonl` — текстовые фрагменты образовательных материалов и связанные с ними данные.
- `data/embeddings.npy` — векторные представления текстовых фрагментов.

Файлы индекса могут быть предоставлены отдельно либо сформированы модулем `rag/ingest.py` на основе базы знаний.

### Пользовательские данные

Профили пользователей, история диалогов и напоминания сохраняются в локальной базе SQLite (`bot.sqlite3`).

Дамп организаторов, поисковые индексы, пользовательская база и рабочие ключи не публикуются в открытом репозитории.

## Пошаговый сценарий проверки

После запуска проекта через Docker откройте Telegram-бота и выполните следующие действия.

**Шаг 1. Проверка запуска**

Откройте бота [@AlfaBroHelperBot](https://t.me/AlfaBroHelperBot) либо тестового бота, подключённого через собственный токен.

Отправьте команду `/start`.

Ожидаемый результат: бот отправляет приветственное сообщение и отображает главное меню.

**Шаг 2. Проверка ответов по базе знаний**

Отправьте вопрос:

«Какие документы нужны для регистрации ИП в России?»

Ожидаемый результат: бот формирует ответ на основе базы знаний «Альфа-Курса» и предлагает релевантные образовательные материалы.

**Шаг 3. Проверка ссылок на материалы**

Откройте ссылку из рекомендаций бота.

Ожидаемый результат: ссылка ведёт на соответствующий материал образовательной платформы «Альфа-Курс».

**Шаг 4. Проверка уточнения запроса**

Отправьте неоднозначный вопрос:

«Как открыть бизнес?»

Ожидаемый результат: при недостатке информации для точного ответа бот запрашивает уточнение.

**Шаг 5. Проверка обработки отсутствующего ответа**

Задайте вопрос, информация по которому отсутствует в предоставленной базе знаний.

Ожидаемый результат: бот сообщает об отсутствии достаточной информации вместо формирования неподтверждённого ответа.

**Шаг 6. Проверка профиля**

Откройте раздел «Мой профиль» и заполните сведения о пользователе.

Ожидаемый результат: профиль сохраняется и используется при персонализации рекомендаций.

**Шаг 7. Проверка напоминаний**

Откройте раздел «Напоминания», создайте разовое или повторяющееся напоминание, затем проверьте возможность его просмотра и отключения.

Ожидаемый результат: напоминание сохраняется и обрабатывается системой.

**Шаг 8. Проверка истории диалога**

Задайте несколько связанных вопросов в одном диалоге.

Ожидаемый результат: бот учитывает предыдущие сообщения при формировании ответа.

**Шаг 9. Проверка сохранения данных**

Перезапустите контейнеры Docker и повторно откройте бота.

Ожидаемый результат: ранее сохранённые профиль, история диалога и напоминания остаются доступными.

## Известные ограничения

- **Зависимость от базы знаний.** Бот отвечает на вопросы в пределах доступного образовательного контента. Полнота и актуальность ответов зависят от предоставленных данных.
- **Зависимость от внешних API.** Для генерации ответов необходим доступ к GigaChat API, а для работы Telegram-интерфейса — к Telegram Bot API.
- **Возможные ошибки генерации.** Языковая модель может формировать неточные ответы, поэтому важную информацию рекомендуется дополнительно проверять.
- **Доступность ссылок.** Переходы к образовательным материалам зависят от корректности адресов и доступности платформы «Альфа-Курс». Некоторые материалы могут требовать авторизации или оплаты.
- **Налоговый календарь.** Информация носит справочный характер и не заменяет проверку актуальных сроков в официальных источниках.
- **Локальное хранение данных.** Профили, история и напоминания сохраняются в SQLite. Демонстрационная версия не предусматривает отдельной распределённой системы хранения пользовательских данных.
- **Доступность бота.** При локальном запуске через Docker бот работает только пока запущены контейнеры и доступно интернет-соединение.
