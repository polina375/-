# Альфа-Курс: ИИ-помощник для предпринимателей в Telegram (Трек 2)

## Назначение
Бот в Telegram помогает начинающим предпринимателям и владельцам малого бизнеса:
отвечает на вопросы по базе знаний «Альфа-Курса», уточняет неясные запросы,
честно сообщает, если ответа в базе нет, рекомендует бесплатные и платные материалы
и напоминает об обучении и важных событиях в бизнесе (TODO: Участница 1).

## Архитектура
```
Telegram ──► bot/ (интерфейс, профили, напоминания)
                │  answer(user_id, text, profile, history)
                ▼
            rag/assistant.py
              ├─ retriever.py   гибридный поиск: BM25 + эмбеддинги (RRF), порог схожести
              ├─ llm.py         OpenAI-совместимый LLM API (по умолчанию YandexGPT)
              ├─ prompts.py     ответ только по базе, статусы answered / clarify / no_answer
              └─ recommender.py подбор бесплатных и платных материалов с учётом профиля
PostgreSQL (дамп каталога) ──► rag/ingest.py ──► data/ (чанки + эмбеддинги)
```

## Быстрый запуск (одна команда)
1. Положите файл дампа в `data/alfa_course_hackathon.backup` (данные кейса в репозиторий не входят).
2. `cp .env.example .env` и заполните `LLM_API_KEY`, `LLM_MODEL`, `LLM_PROJECT`, `TELEGRAM_BOT_TOKEN`.
3. Запуск:
```bash
docker compose up --build
```
При первом запуске восстанавливается дамп в Postgres и строится индекс, это занимает несколько минут.
Повторные запуски быстрее: индекс уже лежит в `data/`.

## Переменные окружения
| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | подключение к Postgres с каталогом (по умолчанию контейнер `db`) |
| `POSTGRES_PASSWORD` | пароль Postgres в compose |
| `DATA_DIR` | папка с дампом и индексом (`data`) |
| `MIN_COSINE` | порог схожести, ниже него бот считает, что ответа в базе нет |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, `LLM_PROJECT` | LLM: по умолчанию YandexGPT через OpenAI-совместимый API |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather |

## Подключение LLM
Используется YandexGPT (Yandex Cloud, сервисный аккаунт с ролью `ai.languageModels.user`).
Ключ создаётся в консоли Yandex Cloud и кладётся в `LLM_API_KEY`, идентификатор каталога
подставляется в `LLM_MODEL` и `LLM_PROJECT`. Другой OpenAI-совместимый провайдер подключается
сменой трёх переменных без правок кода. Рабочие ключи в репозиторий не входят.

## Входные данные
Выгрузка образовательной платформы «Альфа-Курс» (PostgreSQL, `.backup`): статьи, документы,
глоссарий, калькуляторы, вебинары, подкасты и описания курсов. Что попадает в индекс:
- бесплатные материалы: название, описание и тело (блоки содержимого);
- платные материалы и курсы: только название и описание. Тексты платных уроков не индексируются
  и в LLM не отправляются;
- `Courses.Cost IS NULL` трактуется как бесплатный курс.

## Как работают сценарии
- **Ответ есть в базе:** поиск находит фрагменты, LLM отвечает только по ним, бот предлагает материалы.
- **Неоднозначный вопрос:** статус `clarify`, бот задаёт один короткий вопрос, история диалога учитывается.
- **Ответа в базе нет:** статус `no_answer` (порог схожести + правило в промпте), бот честно об этом говорит.
- **Платные материалы:** одна фраза о пользе и ссылка на страницу, без раскрытия содержания.
- **Приватность:** во внешний LLM уходят только нужные фрагменты бесплатного контента и профиль
  без персональных данных. Для демо используются тестовые профили.

## Известные ограничения
- Качество зависит от полноты базы: на вопросы вне базы бот отказывается отвечать.
- Порог `MIN_COSINE` подобран на небольшом наборе тестовых вопросов.
- Платные материалы описываются без деталей, как требует кейс.
